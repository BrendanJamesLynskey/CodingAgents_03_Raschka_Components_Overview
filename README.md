# CodingAgents 03 — Components of a Coding Agent — Overview

A companion to Sebastian Raschka's article *[Components of a Coding Agent](https://magazine.sebastianraschka.com/p/components-of-a-coding-agent)*. This is the first of five decks unpacking his framework for what actually goes into a working coding harness like Claude Code or Codex CLI: the harness mental model, the LLM / reasoning model / agent distinction, the four-step `observe → inspect → choose → act` loop, and the six-component architecture.

Designed to be read alongside the article — it gives the framing, then points to the four detailed decks that take each component in turn.

**Live site:** https://brendanjameslynskey.github.io/CodingAgents_03_Raschka_Components_Overview/
